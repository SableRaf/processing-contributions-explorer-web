About this page

If you’re having trouble with the built-in Contribution Manager, please try the latest version of Processing first, available at processing.org/download.

If the Contribution Manager is still unavailable, this page provides an unofficial fallback for browsing and downloading Processing libraries, modes, tools, and examples.

Install a contribution manually

  1. Download the contribution ZIP using its Download zip button.
  2. In Processing, open Sketchbook folder from the Preferences window.
  3. Open (or create) the folder that matches the contribution type:
    • libraries/
    • modes/
    • tools/
    • examples/
  4. Unzip the contribution into that folder, then restart Processing.
